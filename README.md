# PCL Living Fork 旧版更新兼容入口

主项目已迁移到 **[DDZmumo/PCL-Living-Fork](https://github.com/DDZmumo/PCL-Living-Fork)**。源码、问题反馈和后续开发请前往主仓库。

## 为什么保留这个仓库

旧版 LivingPCL 启动器将 `DDZmumo/LivingPCL2-Re` 固定为更新地址，部分版本还会检查下载链接所属的仓库。主仓库改名后，为继续照顾这些旧版本，保留旧名仓库作为更新兼容入口，供后续发布提供兼容更新信息。

这里不是独立开发分支。旧版程序下载已撤下，历史更新内容已统一收录于[关于旧版本下架的声明](https://github.com/DDZmumo/LivingPCL2-Re/releases/tag/notice-2026-10-24)；当前不提供程序下载，新版发布请关注主仓库。

本项目为第三方修改版本，非 PCL 官方版本。原作作者为龙腾猫跃及 PCL 原项目贡献者，版权归原权利人所有。
